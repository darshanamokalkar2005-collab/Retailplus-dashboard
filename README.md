# RetailPulse: Power BI Dashboards

### Transforming Retail Data into Business Insights

## Project Overview

RetailPulse is an interactive Power BI dashboard project designed to analyze retail sales, customer behavior, product performance, revenue trends, and inventory risks.

The project transforms raw retail transaction data into meaningful business insights using interactive visualizations and key performance indicators (KPIs).

##  Project Objectives

- Analyze overall retail sales and revenue.
- Identify top-performing products.
- Analyze customer purchasing behavior.
- Understand monthly and seasonal sales trends.
- Compare sales across countries.
- Monitor inventory risks.
- Build interactive dashboards for business intelligence.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Excel / CSV
- Online Retail II Dataset

## Dashboard Pages

This project contains 12 interactive dashboard pages:

1. Executive Summary
2. Sales Trend Analysis
3. Product Performance
4. Customer Analytics
5. Region & Country Sales
6. Monthly & Seasonal Analysis
7. Customer Behaviour
8. Profit & Revenue Analysis
9. Inventory Risk
10. Order & Transaction Analysis
11. Advanced Analytics
12. Interactive Filters

## Key Performance Indicators (KPIs)

- Total Sales
- Total Revenue
- Total Orders
- Total Customers
- Total Quantity Sold
- Average Daily Sales
- Monthly Sales Performance
- Top 10 Customers by Sales

## Key Features

- Interactive dashboard navigation
- Dynamic slicers and filters
- KPI cards
- Sales trend analysis
- Product performance analysis
- Customer segmentation
- Country-wise sales analysis
- Monthly and seasonal analysis
- Treemaps, bar charts, line charts, and donut charts

## Project Workflow

1. Import the Online Retail II dataset.
2. Clean and transform the data using Power Query.
3. Prepare and combine datasets where appropriate.
4. Create data models and relationships.
5. Develop DAX measures and calculated columns.
6. Design interactive Power BI dashboards.
7. Apply filters, slicers, and navigation buttons.
8. Analyze retail performance and identify business insights.
